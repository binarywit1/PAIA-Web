# La Machine PAIA — mini-site du bundle

Un seul dossier. Un seul site. Téléphone, tablette, ordinateur.

1. **90 jours** — 13 semaines. Chaque semaine : lire · écrire · un prompt · une preuve radar.
2. **Livre** — Volumes 1 et 2 intégraux (préface → conclusion), Cas d’Afrique illustrés, arme 15 min en bas de chapitre.
3. **Cahier** — 21 mouvements saisissables.
4. **Arsenal** — 100 prompts, recherche, bouton copier.
5. **Radar** — Planner 365 intégré (`#/radar`) : contrat, 12 mois, 52 autopsies, J365.

Notes en **localStorage**. Rien n’est envoyé.  
Radar : clé `paia-planner-365-v1` (les notes déjà prises dans l’ancienne app restent).  
Machine : clé `paia-machine-v1`.

## Héberger

Ce dossier **est** le site. Glissez son contenu (il faut voir `index.html` à la racine) sur Netlify Drop ou Cloudflare Pages.

Détail : `00_DIRECTION/HEBERGER_LA_MACHINE.md`.

Ouvrir `index.html` ou un serveur local à la racine de ce dossier.
